# GitHub / GitVerse API

## Введение

Этот проект использует git-сервисы (GitHub, GitVerse) для хранения исходников и зеркалирования.

- GitHub — основной репозиторий и источник CI/CD через GitHub Actions.
- GitVerse — зеркало для резервного хранения и синхронизации.
- GitLab оставлен как архив и не используется в активной разработке.
